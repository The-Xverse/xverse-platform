# SWE.3 Detailed design and units

Create observation.hpp/observation.cpp with versioned ObservationRecord, ObservationFilter, PayloadObservationPolicy, ObservationOverflowPolicy, ObservationValidity, TapConfiguration, TapHandle, TapSnapshot, ObservationStatus/Result, ObservationHub, and SyntheticObservationSink. All externally visible text and payload storage uses existing bounded core values or fixed arrays; no dynamic growth or external dependency is permitted. Filters match explicit optional logical identities, interaction kind, origin, route, and provider. Metadata-only copies no payload. Bounded payload copies at most the configured nonzero limit and labels complete/truncated/omitted/redacted plus decoded/undecoded schema status without performing schema decoding. Hub capacity and each queue capacity are validated nonzero values within compile-time maxima. Drop-newest leaves queued records unchanged and increments dropped. Coalesce-latest replaces only the newest queued matching logical observation slot and increments coalesced; define exact matching keys. Lossless-validation reserves a slot before provider submission, commits it with the resulting provider outcome, and cancels reservation if provider dispatch cannot occur; full capacity rejects before provider mutation and increments backpressure/degraded counters. ProviderComposition takes an optional non-owning ObservationHub pointer while preserving existing construction and no-tap behavior. It never calls provider code with the hub mutex held and never calls consumer code. Exact handle validation protects poll/snapshot/acknowledge/detach. SyntheticObservationSink is a pull-only test/reference consumer. Tests cover identities, policies, all interaction kinds, accepted/rejected provider outcomes, bounds, stale/foreign handles, concurrency, failure isolation, and the accepted disabled-tap benchmark.
