# SWE.2 Software architectural design

Reworks the rejected provider candidate without adding capability scope. LifecycleController gains minimal read-only declaration accessors that return owned copies only after exact handle authentication, allowing ProviderComposition to compare the caller-supplied RouteSpec and endpoint declarations against the authoritative retained values before provider preparation. Provider implementations return bounded internal operation results; ProviderComposition alone issues public ProviderRouteHandle and ProviderRouteSnapshot values, so an independent conforming provider can participate without minting composition authority. Registration captures and validates descriptor and instance identity before acquiring the registry lock, then stores the captured values without any virtual call under that lock. The agreed sequence is prepare provider while the lifecycle route is validated, activate the provider resource, activate the lifecycle route, then allow submit. Composition performs exact lifecycle and item validation before dispatch, while the provider retains defensive validation. Prior validators gain only an explicit additive-owned-path input; their substantive checks execute unchanged.
