# SWE.3 Detailed design and units

Use value-owned C++20 types with private state and validated factories so invalid public values cannot be constructed. Strong enums distinguish four interaction kinds, endpoint directions, origin kinds, diagnostic severity, and validation phase. Bounded identifiers, versions, timestamps, clock domains, correlations, route/provider identities, and payload views have explicit limits. A small result type returns either a valid value or a non-empty immutable diagnostic sequence without exceptions or hidden I/O. Diagnostic ordering and codes are stable. Const access is thread-safe because values own their storage and never mutate after construction. The library performs no filesystem, environment, process, socket, discovery, or legacy access.
