# Design and verification plan

Adds the first runtime-adjacent X-COM C++ library target under src/xverse/xcom, limited to immutable domain-neutral contracts, communication-item metadata, bounded identifiers and payload values, deterministic diagnostics, and validated construction results. It has no route, endpoint, provider, transport, observation, stimulation, gateway, or XDL plan behavior.

- XCOM-CORE-TYPES: Implement only the capability-007 core-types slice. Add the src/xverse/xcom CMake target and domain-neutral immutable C++20 contract, item, bounded identity/value, result, and deterministic diagnostic units. Add table-driven unit and negative tests, a separate external-consumer integration fixture, warning-clean Doxygen configuration and documentation, a machine-readable bidirectional traceability artifact, and scripts/validate_xcom_core_types.py implementing all five declared checks. Preserve the accepted root offline dependency envelope. Do not add endpoint/route lifecycle, providers, transport, XDL plan compilation, observation, stimulation, journaling, time authority, leases, Protobuf/gRPC, gateways, dashboards, or compatibility behavior. Do not modify protected paths or fetch/install dependencies.; checks: VM-XCOM-TYPES-UNIT, VM-XCOM-TYPES-LINT, VM-XCOM-TYPES-STATIC, VM-XCOM-TYPES-INTEGRATION, VM-XCOM-TYPES-VALIDATION
