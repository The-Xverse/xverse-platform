# SWE.3 Unit specifications (EARS)

## XCOM-VAL-UNIT-001 — ComposablePredecessorValidators [event_driven]

When a predecessor validator inspects an integrated candidate, the composable predecessor validation unit shall admit only its original catalog plus explicitly enumerated accepted later-capability paths and shall execute every original gate.

Source: XCOM-VAL-001 and XCOM-VAL-003.

Verification intent: Run the three predecessor --all measures and negative finite-catalog inspection.

## XCOM-VAL-UNIT-002 — ExactCandidateRegressionRunner [event_driven]

When observation validation invokes predecessor regression, the exact-candidate regression runner shall use a private clone detached at the host-supplied exact candidate for every complete predecessor command.

Source: XCOM-VAL-002 and XCOM-VAL-004.

Verification intent: Run VM-XCOM-VAL-OBSERVATION and inspect retained candidate identities and documentation.
