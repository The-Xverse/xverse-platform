# SWE.3 Detailed design and units

The external manifest is a strict immutable list of file, SHA-256, and size records. A separately compiled policy lock carries exact Debian package names, versions, sources, licenses, and generated-code provenance; dpkg-deb metadata and repository documentation are checked against it. DependencyManifest validates identities before any executable probe. PayloadBinding extracts the complete payload of every locked archive into a temporary reference tree and compares its file types, bytes, and symlink targets with the explicit offline prefix. ToolchainProbe executes admitted tools only after manifest, archive, metadata, and payload prerequisites pass and converts expected filesystem, Unicode, subprocess, timeout, and temporary-directory failures into stable JSON diagnostics. BuildEnvelope configures and compiles through CMake-selected CXX, rejects policy-negating flags, and proves effective warning-as-error behavior with a negative compile fixture. DocumentValidation checks each required engineering document independently.
