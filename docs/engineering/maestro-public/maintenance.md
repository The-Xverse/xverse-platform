# Public execution prototype maintenance

Capability022's bounded public platform boundary is user-accepted; concrete
Studio/Autoverse integration remains open. The original closed runtime service and
public preparation path are unchanged. This module does not confer their readiness,
containment, physical-device or legacy-environment approvals.

Use only trusted installed providers. They must interpret supported authored
semantics, reject the remainder before effects, freeze actual effective documents
and private data, report separately pinned installation identity, enforce their
installation reservation, and retain every acquired handle before a call can fail.
Review each provider's deadline and cleanup behavior with actual resources.
Metadata or a passing generic fixture never admits another provider.

Register the native Linux runtime under a private canonical host root and bind the
host permit to service.runtime_binding_digest. Do not deserialize host permits,
executable bindings, schema paths or provider objects from projects or HTTP input.
Review executable/script content pins and actual command/environment identity after
upgrades. Re-inspect effective inputs and issue a grant for the exact new candidate.

Reads are historical observations with original monotonic clock domains. Use the
explicit observe operation for actual resource checks. Do not compare unrelated
clock domains or treat startup readiness as continuing functional fitness. A host
timer owns the whole-run budget independently of browser sessions. Keep evidence
capacity finite; explicit observation consumes Argus's bounded event capacity.

Native providers expose optional pure observation_clock_declarations and bounded
read_observation_batch. Register clock origins before opening Argus; do not infer a
host/native mapping. Collection accepts no browser-supplied records. Preserve original
input events, observations and snapshots, and retain source sequence gaps separately
from native drop/coalesce counters. Native retention-time counters do not include
later loss; final quiesced native snapshots are required to establish interval closure.
Unknown upstream causation stays unset, while forwarding can cite the actual source
input event. Repeated source batches and lost-response Stop retries must be inert.

On partial start or writer failure, cleanup must proceed for all attempted acquiring
phases. Unknown ownership never permits a signal. ProcessOwnershipError retains a
partial child for provider bookkeeping. Whole-tree cleanup is unsupported: a
provider must independently own each descendant/resource it claims to release.
Evidence writer failure and resource release are separate outcomes.

After a backend crash, durable claims prevent replay. This prototype deliberately
does not reconstruct resource authority from journal IDs or PIDs. It returns
MPX-ORIGINAL-OWNERSHIP-UNAVAILABLE and blocks new activation in that root. An operator
must reconcile the installed provider's resources through its approved interface;
do not delete claims or choose a new root as a bypass. A future reviewed recovery
capability may close this limitation. Preserve original Argus evidence throughout.

Rebuild/reinstall the package after source edits: force-included xverse modules are
copied even during editable installation. Verify installed/source byte equality,
run tests/maestro_public plus affected baseline regressions, retain exact source,
test/report hashes and bounded results, then conduct a separate review. Present
the concrete candidate for user acceptance before exact main integration. Never
replace failed evidence or imply that these tests establish native X-COM, Autoverse,
Studio views, Windows, real-time guarantees or hostile-code isolation.
