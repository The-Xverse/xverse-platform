Detailed Description

Opaque handle addressing one live validation session.

Authenticity rests on the issuing SessionManager's internal table plus the host- controlled uniqueness scope (opaque issuance), not on cryptography. A handle binds the issuing manager scope, controller identity, generation, and session identity; it is meaningful only with the matching scope, controller identity, and generation, and is a bounded prototype control.
