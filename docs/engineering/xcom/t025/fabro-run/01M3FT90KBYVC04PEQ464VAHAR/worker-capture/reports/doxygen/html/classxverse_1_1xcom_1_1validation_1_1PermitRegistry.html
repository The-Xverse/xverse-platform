Detailed Description

Controller-scoped, exactly-once consumed-identity bookkeeping.

try_consume performs a single atomic check-then-insert under this registry's own mutex, so N concurrent consumptions of one identity yield exactly one Result::Ok and N-1 deterministic failures. Check order is session identity first, then permit identity, then capacity, so a changed-nonce replay is reported as Result::SessionAlreadyConsumed. No partial insertion occurs on any failure, and the bookkeeping never grows past its configured capacity. The registry is non-copyable and non-movable.
