Parameters

The absolute difference as an unsigned 64-bit value, exact over the entire signed 64-bit domain (maximum UINT64_MAX). The magnitude is computed from the ordering of the original signed values, so it never wraps modulo 2^64 and never treats the top bit as a sign bit.
