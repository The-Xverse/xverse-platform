Detailed Description

Lifecycle state machine of one validation session.

A ValidationSession owns its lifecycle state and per-session remaining quota. It is reached by SessionManager only while that manager holds its single mutex, which gives a deterministic total order; it is not individually synchronized. It is copyable and movable because it is a plain value once created.
