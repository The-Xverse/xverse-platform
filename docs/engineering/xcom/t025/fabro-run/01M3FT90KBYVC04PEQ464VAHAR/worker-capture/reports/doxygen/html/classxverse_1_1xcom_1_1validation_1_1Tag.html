Detailed Description

Bounded printable-ASCII tag (at most 63 bytes, no NUL).

Used for the scenario, deployment, environment, tool, interface, and target fields. Construction does not validate; use make or is_valid at a validation boundary. A Tag is an immutable value safe to copy across threads.
