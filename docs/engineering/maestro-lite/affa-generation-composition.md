# Original generation/epoch bridge — next required composition

DRAFT detailed design,18 October2026. Completes the planned AFFA17 scope, not an
alternate whole-run-restart design. Existing AF17 v2, all24 ML-SR,18 source parents,
30 scenario pairs/90 endpoints and nine runtime cases remain governing.

## Verified facts and incompatible assumptions

Native ADVANCE already retains old-generation handles/facts, confirms actual old
boundary removal, installs a watched fresh C1 FD, advances one shared epoch and
burns unused tickets while unrelated running resources remain owned. Its component
controls do not admit a new M3 execution or mutate an original C1 admission.

The actual Python C1 registry currently accepts only its original creation epoch;
release_epoch is initial_epoch plus the cancellation latch. The actual worker and
PermitSession currently admit generation1 for every unit. A selective restart of A
must not require B's unchanged generation1 execution or permit to be re-created.
Changing a global initial_generation to2, mutating the checked permit tuple or
resetting the worker is therefore not an implementation of selective restart.

## Required authority/evidence sequence

1. Original controller request selects only a pre-admitted unit generation/context.
   The original broker retains exact fresh PermitBinding/PermitApproval/execution/
   nonce and artifact pins. An untrusted controller cannot supply approval objects,
   invent contexts or generate fresh permissions from an integer budget.
2. Stop and release active transitive dependents in reverse original dependency
   order. Record their actual normal stop/cleanup intents/outcomes and native waits
   separately from C1 membership/removal. No new start may use their old readiness.
3. Stop/retire the target through its original AFFA handle, observe its original
   native direct-child wait, release the exact original C1 boundary, and retain
   those observations under its old generation. Missing proof blocks advance.
4. Admit a fresh original C1 boundary under the current original verified epoch;
   WATCH it before native ADVANCE. Pin unchanged productive image/recipe/cwd/action
   and fresh original execution/permit context. The same surviving original worker
   consumes its fresh intent and writes/flushes the real Argus mirror.
5. Native ADVANCE receives that actual proof and new original watched C1 descriptor,
   validates old release and budget, and returns its actual new shared epoch. A
   private original receipt, retained by the issuing connection, authorizes the C1
   bridge to recognize that epoch for later fresh boundaries. Raw integers, equal
   copied receipts, public metadata and mutable counters do not authorize it.
6. Retire readiness for the affected dependent set and pending old-epoch tickets.
   Retain unrelated original running units, handles and normal evidence. New Stage,
   Arm/Release and fresh prerequisite probes use the actual new generation/epoch.

## Original registry changes required

Keep BoundaryAdmission immutable. Extend the original C1 registry with a separately
pinned original native epoch bridge and an append-only set of admitted creation
contexts. Old C1 cleanup capabilities remain valid for their original descriptors.
Native cancellation proof, local cancellation intent and unknown issuer-loss epoch
remain distinguishable; never label the latch as a native M1 acknowledgement.

Keep the original worker, journal, writer and per-unit old-generation contexts.
Extend permit admission with an explicit original generation operation for one unit;
validate its exact fresh approved binding without replacing unrelated bindings or
weakening the public initial-generation API. Claims, samples, teardown states and
normal records become generation-qualified. Prior contexts stay available for old
cached cleanup/recovery facts; a new claim cannot replay an old consumed nonce.

Every shared journal/Argus consistency check must include the original history and
all retained claims. Before consuming a restart permit, require the original
normal stop/cleanup evidence and original broker's actual issuance/C1-release
statement. A generation number or a saved digest alone is not release evidence.
No Argus root is reopened. A successor run is a distinct root; selective resource
restart within an open original run retains that original writer's history.

Required real controls include A generation1→2→3 with B still live, stale ticket
rejection after each global epoch, old cleanup facts unchanged, absent/expired/
replayed fresh approval or nonce, actual missing old release/normal record, stopped
storage/AFFA during advance, newly created C1 with wrong epoch, dependent quiescence
and fresh probes. Complete dispatcher/teardown/controller composition before a
stable increment17 freeze; none of this design is runtime acceptance evidence.
