## Original admission and native separation

RunBroker admission optionally reserves an explicit0..16 controller-session budget
(default0 preserves prior behavior). Admission checks all original unit generation
scopes + storage/AFFA helpers + controller budget fit explicit C1 capacity before
native authority birth. Each controller uses a fresh original own helper leaf and
fresh admitted session label. Keep original issued controller/child/channel objects;
reject duplicated sessions, budget overflow, copied/forked/reconstructed proxies,
foreign broker/root and any still-live previous controller before mutation.

BS17 adds private birth role5, using the already admitted sealed Python image3 with
fixed '-I -m xverse.maestro.controller_worker channel config' argv. It transfers only
the private request channel and sealed controller input through exec. It inherits no
workload/helper/parent descriptor, native channel, permit or mutable broker registry.
The native birth path rejects watched workload boundaries and previously used helper
identities. BS10 still rejects role5. BC17/BS17 framing remains v2; this is an additive
role in the unfinished private draft contract, not an accepted public wire change.
Controller death does not activate the global storage/AFFA death path. Original BS17
lease/supervisor loss still kills every helper and freezes exact original leaves.

## Strict private requests and clock separation

The sealed controller input contains only version/run/lifecycle/session and the exact
admitted public unit/action vocabulary. Hash its canonical bytes as the private
channel scope. Strict bounded frames bind version/kind/sequence/scope/session and
body, reject duplicates/unknown fields/nonfinite values and unexpected rights, and
verify the actual original peer credentials. Dispose every received FD on rejection.
A finite heartbeat/request ACK establishes only channel liveness/proposal identity.
It is not readiness, ownership, a durable outcome, an execution permit or authority.

Each new controller has a new host clock session. Its local observed time is labelled
with that session and is never subtracted from the surviving broker's host readings.
The original broker alone retains the absolute operation end and bounds every reply.
Worker processing uses a finite duration budget in its own clock session; original
absolute ends are not compared across sessions or extended by a reply. Real workload
probes/evidence continue using the original broker's declared host/UTC domains. No
new controller-local time is inserted into an undeclared Argus clock domain.

## Death, replacement and real reconciliation

Retire an old controller channel only after actual original pidfd death and original
parent wait. Termination is confined to that exact helper. Its own C1 empty/release
is distinct from the workload registry. Repeated retirement returns retained facts;
metadata/timeout alone is not a completed wait. Storage/AFFA and unrelated workloads
must demonstrably remain live after actual controller exit, before successor birth.
A stalled/lost current controller closes request admission until original death is
confirmed. It cannot strand a new native release outside the original broker end.

Replacement revalidates the original surviving per-unit issuers and exact durable
handles/consumption through the original worker, invalidates all old positive views,
and uses a fresh ProcessReadiness view. Extend IssuerRecovery explicitly for genuine
RunUnitIssuer plus this exact original replacement session; preserve existing default
recovery's observation/cleanup-only no-start behavior. The replacement first has no
fresh-ready credit. Only new actual original native observations and normal worker
probe records can establish fresh health. Missing/contradictory evidence stays
cleanup-only/unresolved and closes starts; no public metadata adoption.

After successful replacement reconciliation, the current original controller may
service subsequent explicitly requested operations through the original broker;
old views/channels/session requests must reject. No automatic restart, new permit,
new writer root, old operation end extension or reconstructed authority is allowed.
Generation-qualified recovery, dispatcher/run closure and U7/U8 must be completed
before the full selected M1 increment17 can be frozen, committed or presented.
