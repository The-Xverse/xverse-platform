# Original bootstrap-bound AF17 transport

DRAFT private broker component. Specify before implementation. This is not an
operator admission, execution permit, public facade or competing XDL contract.

Only the original BS17 session factory constructs this transport, after the single
original role4 child has been born/activated. The immutable config is bound before
birth and every initial boundary must be present in the original acknowledged WATCH
inventory. Pin original child, exact socket FD identity, config bytes, session and
original registry entry. A fork/copy/replaced registry or child is rejected.

Each ordinary exchange is nonblocking with respect to other exchanges. Match all
reply fields to the original request, not just shape: seq, original absolute end,
scope, unit, generation, op/proof, expected epoch transition and exact known handle/
ticket. Unknown issued token/ticket is accepted only from the real original native
peer under its corresponding STAGED/ARMED response. Check actual SCM_CREDENTIALS,
exact rights count, CLOEXEC and real pidfd type. Retain original pidfd capabilities
until explicit post-wait disposal; never re-open a public PID. Release cannot extend
the original Arm end. Ready is not Stage or readiness evidence.

The transport does not accept commands from a controller or claim that caller hashes
are actual M3/Argus proof. A trusted original broker adapter must supply those from
actual storage-worker results and enforce fresh generations/dependent quiescence.
That integration remains mandatory. Every ADVANCE FD must match an already watched
original C1 descriptor before transmission. No raw controller-provided FD is allowed.

A late/malformed/wrong-peer/uncorrelated response or extra rights closes starts;
all received rights are disposed. Independent revocation does not acquire the
ordinary exchange lock: latch cancellation, kill via original helper pidfd, and
observe its original-parent wait within the original bounded cleanup end. Unknown
wait/freeze remains unknown. Watchdog freeze and C1 cleanup are separate facts.
The independent native bootstrap retains its exact workload inventory throughout.

Expected tests: real bootstrap factory and typed connection, native two-unit
Register/Intent/Stage/Arm/Release/Cancel/Stop/Retire, exact peer/response/pidfd checks,
local operation/ticket scope rejection, stopped issuer with a concurrent blocked
exchange and independent actual death/wait, fork/copy rejection, new boundary not
watched before Advance, real invalid frame response and cleanup gaps retained.
