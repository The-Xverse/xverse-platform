## Original universe and pure coverage

Freeze canonical obligation templates before any workload from the original verified
PreparedLifecycle, exact inert approved generation contexts, declared cadence and
positive active interval/operation bounds, original steps and required artifact paths.
Include every logical unit and step, even when blocked or never issued. Future
contexts remain conditional scopes in the original universe; they confer no start
permission. Store the original bytes/digest in runtime admission and supply that
same externally pinned admission to offline verification. The recorded report or
arrived event list can never supply a smaller replacement universe.

Logical units each have one terminal unit-disposition requirement and every admitted
step has one terminal step-disposition. Per-generation conditional normal records
include intent, issuance, start outcome, readiness where dependent, health slots,
stop and cleanup. Never-issued units use explicit zero-generation dispositions;
never create an M3 claim/start/stop merely to document a blocked unit. Inactive future
contexts require positive complete original broker/terminal evidence for their
not-applicable predicate. Missing or contradictory predicate evidence is unverifiable.
Use stable digest-based obligation IDs when original XDL logical IDs exceed the
report schema's128-character bound; retain the full original unitId in each row.

Health slot expectations come from original cadence and the bounded actual active
interval under the original broker's host domain. Use genuine retained operation
brackets/terminal facts, not the last arrived health record. Missing closing bounds
conservatively retain admitted bounds rather than shorten the interval. Never
subtract replacement-controller readings from original session readings; readiness
must cite actual generation-qualified acknowledged probes. Each exact slot remains
visible even when simulation ticks pause or a slot's normal record is deleted.

The pure assessor consumes only original templates and retained public inputs. It
must not import a provider, launch helper, scenario, metric or oracle. Verify whole
annotation/source/link/ordering identities, distinguish duplicate identical IDs from
valid separate facts, and preserve contradictory/missing rows. Row expectation and
applicability digests exclude candidate satisfaction decisions. Mandatory normal
records and emergency facts are assessed independently. Provisional overallStatus
is always incomplete, even for fully satisfied normal rows. Coverage completeness
never changes execution/cleanup outcomes.

## Real retained inputs

Retain the exact original caller-owned intent annotation fields and actual returned
ordinal at the append boundary in the original worker. Do not reconstruct caller
fields from a reader or infer unreturned writer fields. Other current event producers
already retain their own supplied fields; export them without adding writer-owned
properties. Original public M3 sources remain the accepted public_records projection.

Export sanitized original broker facts from genuine retained native ACK/receipt
objects: complete admitted unit/generation inventory, actual issuance attempt/ACK or
unknown, original epoch progression and actual normal waits/release facts. Include
original sealed image/claim references only as public-safe digest/IDs. No native
frames, raw handles, descriptors, scope capabilities, PID, permit nonce or ticket.
Public projections grant no runtime authority. An unacknowledged Stage is unknown;
never-attempted and known-issued are different actual facts.

Keep large retained snapshots in bounded confined declared evidence artifacts, not
an unbounded64-KiB private RPC reply. Return their actual public record_artifact
entries, then collect/verify bytes through the original admitted root. Preserve all
partial records when persistence or acknowledgement fails; do not fabricate a
missing export by replaying a permit or inferring a native outcome.

## Runtime ordering and independent closure

Integrate original broker/replaceable controller/dispatcher/generation semantics,
including lazy genuine issuance where an admitted dependency remains blocked. Do
not require every unit to acquire a claim/handle solely so it can receive a terminal
disposition. Keep legacy BS10 component behavior separately compatible.

After active work, fence future releases, perform bounded reverse teardown, and
collect only quiescent owned declared outputs with the original U8 admission. A
live/unresolved unit's output cannot gain trusted/complete evidence credit. Retain
actual indexed entries/bytes and collection missing/error dispositions. Emit exact
logical unit/step dispositions and factual run-terminal/run-disposition only after
teardown/collection. A writer failure leaves an in-memory incomplete result and
last durable manifest authoritative.

Compute provisional coverage; persist/index lifecycle-coverage.json at its original
admitted relative path; then attempt permitted finalize or abort based on actual
normal coverage and writer usability. Do not finalize a missing-record report,
reopen a closed/failed writer or use private Argus state. Keep writer stage/usability,
last durable manifest, recorded/assessed Argus state, lifecycle coverage, execution
and cleanup distinct. RunClosure's current incomplete abort remains until the full
normal evidence path actually justifies another branch.

Offline verification independently rederives expectations from original admission,
reads closed evidence through the accepted reader, verifies actual artifact/report/
manifest identity and preserved diagnostics, and compares retained caller fields
and own recomputed rows with the report. Exclude the report's own admitted path and
only the three reserved writer kinds to avoid recursion. Never rewrite after
closure. Open/failed closure, missing/altered report, corruption or disagreement
remain incomplete/unverifiable.

Required controls include every independent design deletion mutation: whole unit,
issuance/intent projection, health slot, obligation row, forged not-applicable row,
step disposition, blocked-unit disposition and altered report. Exercise nominal
complete, complete documented failure, emergency-complete/normal-gap, all persistence
failure and actual blocked/never-issued paths. Then run all nine full runtime cases,
full admission/M1 races, source/wheel/platform checks and separate full-candidate
review before increment17 can become a stable committed checkpoint. No acceptance,
merge, scientific protocol choice, canonical-note edit or factory run is implied.
