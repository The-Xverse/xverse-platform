# Actual evidence at use and original whole-lifecycle composition

Status: DRAFT refinement before code, finding272. Extends RUNTIME-0001/0002;
no change to hash-bound external design, author acceptance or scientific scope.

Add read-only evidence-file verification over explicitly supplied descriptors.
Read exact canonical authorization/facility bytes and all nine separately pinned
receipt bytes under one original host deadline. Bound each file to1MiB, all files
to11MiB, pread in16KiB chunks without altering caller offsets, and reject
nonregular/changed/truncated/mismatched input. This is engineering input handling,
not a new XDL or receipt schema. The externally approved facility attestation owns
receipt semantics; hashes do not authenticate their author or prove full coverage.

At use also compare actual kernel release, original C1 parent identity/cgroup-v2
controls and empty inventory/population, cancellation/end scope and current
self-pidfd/KCMP support. These checks create no process, C1, journal or writer.
They cannot replace the nine actual capability cases, external host supervision,
source-parent dispositions or separately approved bootstrap authorization.
Return descriptive pins with execution readiness false; synthetic test files
must never be used as execution authority.

Separately add a private original whole-lifecycle composition component. Its
trusted caller already owns the explicit low-level bootstrap/permit scope. It
retains one original launcher/config/unit tuple and fixed startup, active,
terminal and closure ends; one start attempt owns storage, exact C1 units,
native authority/controller, existing lazy dispatcher, collection/report and
RunClosure. Matching completed start returns its result; changed repeats and
concurrent starts reject without mutation. Cancellation remains independent,
sets the original latch first and routes through the actual active dispatcher or
original startup owner. No hidden retry, new writer, PID discovery or adoption.
Retain failed startup/root identity, unknown waits, terminal/closure diagnostics
and exact cleanup owner; disposal requires actual original root/helper waits.

Python composes existing components; native BS17/AFFA still own fencing and
direct waits. No production C behavior or existing accepted exports changes.
Owned tests may execute this private component using their separate original
bootstrap/permit approval, without synthetic facility metadata. Public admission,
full active control registry/API, complete M1/source-parent/case/regression/review
and stable17 remain required. Implementation of these components is not delivery
of a public approved run path or a full facility proof.
