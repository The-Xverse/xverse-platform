# Owned native writer stream fault facility

Status: DRAFT engineering selection before implementation. Existing increment17
W02/W03 obligations only; no production fault API, new factory admission, full M1
or scientific scope change. See finding244 and writer-stream-fault-facility.md.

Select C for the exact owned write/close interposition boundary and the existing
native BS17 derivative. Python owns fixed public-method observations and checks.
This is an owned test fixture, not an X-COM data-plane or production module.

Compile one fixed library per owned fixture with mode, owned public events.jsonl
path and separate syscall trace path embedded before any helper birth. Restrict
matching to writable regular descriptors with the exact admitted public pathname
and matching current file identity; never inspect, replace or obtain the private
Python stream. No content, permits or authority descriptors enter public traces.
Keep finite counters/trace sizes and record unsupported interposition honestly.

Embed the compiled ELF bytes in a copy of the exact original bootstrap source.
Only its role3 child creates and fully seals an inert memfd after the inherited
close-on-exec sweep, clears its CLOEXEC bit and passes a fixed LD_PRELOAD entry.
All other roles retain the original empty environment. Bootstrap hash admission
therefore binds the exact ELF and fixed code before birth. Preserve original
credentials, no-new-privileges, original parent/child/channel checks, C1 containment,
lease/watchdog and original deadline mechanisms. Check the complete source delta;
do not add an ambient opt-in or modify production bootstrap.c.

The fixed role3 Python wrapper must demonstrate the actual loaded global library
symbol, sealed image digest and public operation ordering, then call the original
persistence_worker.main. A fixed role5 observer demonstrates absent preload and
absent injected symbol before its original controller_worker.main. An injection-
disabled control must complete the normal original report/closed verification.

W02 uses the original public flush_buffer, appends a labelled non-Maestro annotation
through append_event, then arms the fixed native write failure. Require the actual
next matching write attempt after the public wrapper returned. A one-shot variant
may establish later fresh public flush usability and bounded abort; a persistent
variant must retain unknown usability/no abort. No expected outcome is selected
from the returned candidate state. If annotation append flushes early or no native
attempt occurs, the mechanism is NOT_DEMONSTRATED.

W03 performs the real matching close first and only after success returns EIO to
Python. Retain both facts and the real subsequent fresh public flush result.
Writer_state=open does not imply usability. Do not reopen a writer, rewrite the
manifest, infer a stage from finalize entry or create synthetic normal evidence.

Before counting either W row, execute exact source and installed-wheel original
native report/closure composition, retain both trace clocks, compile/package/input
identities, actual manifest bytes and independent original helper/C1/root waits.
Keep failed mechanisms and use the selected CAPA process for defects without
claiming formal independent cause confirmation or effectiveness. Loader or syscall
failure keeps the relevant stage unverified. All existing full17 gates remain.

Refinement after original2320, before successor code (finding246): the proposed
successful public annotation cannot seed pending bytes because public append_event
flushes internally. Reject that mechanism and retain its genuine normal closure
as a failed injection observation. The successor uses an explicit failed write
during a labelled non-Maestro fixture annotation, catches/records that fixture-only
public exception, then returns from the original successful public flush wrapper.
Only an actual subsequent native write attempt after that return can demonstrate
the target internal flush failure. A one-shot target variant thus has two native
errors total: one seed plus one target. Persistent mode also rejects the later
fresh policy flush. All seed/target/recovery errors are separately clocked. This
establishes behavior under a preconditioned public append failure, not an isolated
single-fault healthy-prefix W02 case; no broader coverage or normal-event credit
is inferred. No production writer is changed and private stream access remains
forbidden. Loader/W03 proof and old failed controls stay at their exact snapshots.
