## Admission and large inert facts

Add an optional sealed runtime-evidence profile, preserving absent/default v1–v4
bytes and behavior. Bind the original externally pinned coverage digest, exact
source/destination root identity, every per-generation output declaration and
internal artifact path, explicit collection/report budgets and finite byte/event/
RPC capacities before any workload. Apply the original proposed D3 caps; do not
infer timeouts. Reserve teardown, collection, all remaining normal annotations,
report publication and writer closure before active work. Reject profiles exceeding
the original generation end, native helper input bound or event/storage capacity.

Python owns bounded evidence composition; the original native authority still owns
actual workload waits/fencing. Collection, artifact publication, reader I/O and
writer closure run in the original disposable persistence owner. The surviving
supervisor never performs filesystem collection or adopts another writer.

Broker projection may exceed a private64-KiB RPC even though its public bound is
oneMiB. Do not reduce the admitted inventory to fit a packet. Extend only the private
persistence channel with an explicit inert-public-blob operation: one original
sealed read-only data memfd, its actual byte length and externally pinned digest.
It conveys no productive descriptor, process capability, raw handle or ownership.
Authenticate the original peer, require exact ancillary count/type/seals/size,
close every unexpected or rejected descriptor, read within the existing operation
end and verify bytes before any artifact ACK. Other operations retain zero-rights
semantics. The worker rechecks run/lifecycle/context inventory against its own
original admission. It may not turn public facts into permits or readiness.

Before code, record this private descriptor-protocol decision in an owning-repository
ADR and update its exact U7/U8 unit/interface contract. This draft is the design
input to that engineering review, not a completed cross-boundary verification.

The complete profile must explicitly reserve this operation and original collection/
publication costs. Memfd construction/transfer and host/kernel stalls are separate
observations; no hard timing guarantee follows from a byte cap. A failed transfer
retains original unknown facts and cannot publish a successful source digest.

## Full original universe, including never-claimed units

The complete profile cannot require every prepared unit to acquire a start claim
or native Stage merely to receive a terminal disposition. FiniteDispatcher must
accept the original full admitted broker inventory with conditional unissued units;
prepare/blocked bookkeeping uses original admission sources. Genuine first claim,
Stage and Release occur only for the eligible explicitly admitted start attempt,
with existing durable intent, controller proposal, dependency probes and epoch gates.
Keep the compatibility path unchanged when the complete profile is absent.

ScheduleJournal and reply validation must use all prepared logical units/steps as
the terminal universe. A known never-claimed unit/step has generation0 and an
admission-derived source, without fabricated M3/handle/native facts. Issued records
retain their actual original context, including historical generations. Current
claims cannot erase old-generation source/cleanup facts. An unacknowledged attempt
is unknown, not never-attempted. Complete or successful disposition requires its
actual required normal facts; cleanup-only evidence never supplies a lost outcome.

## Actual ordering and immutable artifacts

Split active dispatch from complete-profile terminal publication. Fence further
starts, perform bounded original reverse teardown, then collect only quiescent
declared outputs. Keep per-item missing/error observations, actual indexed entries
and confined accepted bytes. Unresolved/live ownership prevents trusted output
credit; do not claim frozen/terminated from helper reaping alone.

Publish the factual collection result, every logical unit/step disposition and
run-terminal/run-disposition after teardown/collection. Retain caller-owned fields
and actual ordinals. Write/index original broker and retained-input artifacts from
the actual final snapshots; their input digests must match assessment exactly.
Compute provisional coverage over those facts, entries and bytes. Persist/index
the original report once, excluding its own path from the core. Failure preserves
partial artifacts; no overwrite/replay or report rewrite after closure.

## Closure and result

Finalize only when the original required coverage, collection and terminal facts
actually permit it. Otherwise attempt one bounded abort only after a positive public
flush ACK establishes current open-writer usability. After a finalize exception,
an open flag alone does not establish usability: a permitted public flush probe may
establish it, otherwise retain unknown/unusable and do not abort. Never inspect the
private stream, infer an inaccessible finalize substage, reopen failed/closed writers
or report the intended manifest as the durable one. If exact substage is unavailable,
report that uncertainty alongside the actual public state and operation attempted.

CoverageResult.normal_complete deliberately excludes artifact rows and is insufficient
as the finalize gate. Check required artifact/emergency applicability and every
corrupt/conflicting optional item as well, after actual report write/index ACK.
Pre-closure overallStatus is always incomplete by contract; do not require it to
be complete or substitute normalRecordStatus alone. Derive the closure predicate
from the original independently assessed rows and retained factual terminal/collection
observations, keeping authoritative completion for the later closed-reader pass.

The bounded immutable result separates execution, per-generation normal evidence,
native/C1/helper cleanup, collection, writer stage/usability, last acknowledged state,
actual durable manifest hash, recorded/assessed Argus status and lifecycle coverage.
Independent offline verification uses the externally pinned original admission and
accepted closed reader. An in-memory incomplete result remains available when all
persistence fails. Matching repeated stop/collect returns original retained results;
changed run/lifecycle/root identity rejects before any new operation.
