# Default-closed candidate admission service

Status: DRAFT before implementation, finding289. Extends RUNTIME-0001–0004.
No change to hash-bound external design or acceptance/scientific authority.

Add a candidate RuntimeService around original runtime submissions and the private
registry. The trusted host configures a fixed bounded allowlist of externally
approved authorization, facility, design, implementation, environment and readiness
digests. Execution is disabled by default. A submitted request cannot mutate that
policy, approve itself or mint an original run from public metadata. Inspect is
read-only; register/start require explicit host execution mode and approved pins.

Readiness is a separate canonical engineering review record, not XDL configuration
or an execution capability. It binds actual source-parent and independent full
verification review-file digests, the original eighteen parent/nine case scope,
completed review/disposition flags and absence of blocking findings. Read the
actual pinned review files plus existing authorization/facility/nine receipt bytes
under one original finite end. The trusted host must authenticate approval and
validate the semantics of those records before configuring the allowlist; this
library does not become an approval signer or establish truth from declarations.
Current DRAFT/partial/failing evidence cannot be substituted for that approval.

Register only the caller's already-original low-level runtime owner before birth.
Revalidate at first start, preserve exact repeats after terminal expiry, and route
controls through the same original registry. Stop uses its retained cleanup log
even if ordinary policy/map fields are lost; expiry cannot remove cleanup rights.

A fixed typed original start-window restriction is bound before birth. Check
aware UTC after executable hashing/immediately before initial creation and before
startup operations and later helper births/controller allocation. The restriction
never enlarges the separately approved low-level bootstrap scope. Preserve existing
unbound owned-component paths; no arbitrary callback is admitted at the boundary.
Kernel/Popen scheduling and in-flight late resources still require admitted outer
supervision and original bounded cleanup; no atomic UTC/kernel-call guarantee.

Positive synthetic records are inspect-only or final-start-stubbed unit checks
with process/C1/sink effects forbidden. Actual window-denial tests can restrict
an already separately approved owned bootstrap; they never enable it. Full actual
public admission, source-parent/facility/M1 proof, matrices, regression, independent
complete review, stable17 and135/222/286/287 remain open. Keep top-level accepted
preparation exports unchanged pending that complete evidence. Python owns these
