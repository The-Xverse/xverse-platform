# Unit and integration verification allocation

Tests use actual public Core, original owned Linux children and the real Argus
writer/reader. They do not establish physical, hostile-host, arbitrary provider,
Windows, live Autoverse or complete Studio acceptance. Valid-Argus adversarial source
fixtures deliberately alter only their own temporary roots; the retained real
registration is inspected read-only and its byte hashes remain unchanged.

R03 follow-up cases first produced two real red results: a resources object and
unexpected phase metadata on a global event passed the initial verifier. The repair
requires supported typed fields, not just an outer Argus annotation. Nested provider
observation dictionaries remain data; they are never executed or treated as grants.

Eligibility means consistency of original recorded compensation under the trusted
host/provider contract. It is not independent attestation of hardware/resource state
or a recovered resource handle. A host grant is separate authority, and new Start
still needs ordinary current installation, provider and execution-permit admission.
