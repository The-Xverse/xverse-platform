# Interface catalog — M0 public-safe summaries

**Status**: discovery evidence, not approved executable contracts. **O** = observed source,
**D** = source documentation, **U** = unknown. No interface was exercised in M0.
Precise private addresses, message identifiers/layouts, device paths, credentials and source excerpts
are intentionally excluded. Production identifiers remain unchanged. Complete contracts and
representative captures must be reviewed before wrappers or parity claims.

## Contract review required before execution

For each selected component, freeze revision/artifact provenance, direction and message semantics,
units/encoding, failure behavior, startup/readiness and shutdown ownership, discovery assumptions,
clock domains and timing tolerance. Private details belong in restricted review material or later
appropriately scoped descriptors, not copied into this public-safe summary. This is a review checklist,
not a new configuration language or an assertion that these contracts are already approved.
